# Recursos originales de La Guatoca

Los PNG de esta carpeta se exportaron de los objetos `Sprite` del APK local
`base.apk` con UnityPy 1.25.4. El SHA-256 del APK de origen es
`ce25efdc7e1864cc230125f0fcaace322ffb6090ac621d6d69fcbac4fc20816b`.
`manifest.json` vincula cada archivo con su nombre y `path_id` original.

El APK contiene el atlas `Boogaloo-Regular SDF Atlas`; por eso la web usa
`Boogaloo-Regular.ttf`, obtenida del repositorio oficial de Google Fonts. Su
licencia OFL está en `Boogaloo-OFL.txt`.

Los sprites extraídos se conservan como PNG con transparencia. No se modificó
el APK ni se ejecutó la aplicación original.
